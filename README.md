# Java Placement Practice

Standalone Java examples are grouped by concept. Compile any file from the repository root with:

```text
javac "Folder\File.java"
java -cp "Folder" ClassName
```

## Concept map

| Folder | Main concepts |
| --- | --- |
| `JavaConcepts` | variables, data types, operators, conditionals, loops, arrays, strings, collections, exceptions, input/output, methods, enums, wrappers, generics, lambdas, streams, files, date/time, threads |
| `OOPS` | classes, constructors, encapsulation, inheritance, polymorphism, abstraction, interfaces |
| `Functions` | parameters, return values, overloading, recursion, static and instance methods |
| `arrays`, `Day 2`, `Day 3`, `Day 5` | array fundamentals and placement problems |
| `Searching` | linear search and binary search |
| `Sorting` | bubble, selection, insertion, merge, quick, heap, counting, radix, shell, and bucket sort |
| `Node`, `Circularnode`, `doublynode` | linked-list operations and traversal |
| `Stack`, `queue` | stack and queue operations |
| `recursion` | recursive problem solving |
| `Trees` | binary search tree insertion and traversal |
| `Patterns`, `pattrens triangle` | console pattern problems |
| `If-else`, `conditionals-loops`, `revers`, `String` | beginner conditionals, loops, and string problems |

Each source file is intentionally independent so it can be compiled and practiced separately.
