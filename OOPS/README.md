# OOPS Examples

Each topic has three independent examples. Compile a file from the repository root with:

```text
javac "OOPS\01_ClassAndObject\CarExample.java"
java -cp "OOPS\01_ClassAndObject" CarExample
```

| Folder | Examples |
| --- | --- |
| `01_ClassAndObject` | car, student, bank account |
| `02_Constructor` | default, parameterized, and copy constructors |
| `03_Encapsulation` | private fields, validation, read-only fields |
| `04_Inheritance` | single, multilevel, and hierarchical inheritance |
| `05_Polymorphism` | method overloading, method overriding, runtime polymorphism |
| `06_Abstraction` | abstract class, abstract vehicle, template method |
| `07_Interface` | printable interface, multiple interfaces, default method |
